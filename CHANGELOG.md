# Changelog

Changes in the latest Commit+ release compared with the previous release.

## v1.1.11

Changes since `v1.1.10`.

### Added

- **Custom Actions** — Configure executables or scripts in Settings and run them for a repository, selected files, or selected commits. View command output and sync action definitions and embedded scripts through Commit+ Cloud, with execution trust managed separately on each Mac.
- **Line change counts** — See added and removed line totals beside files in File Status, commit details, and comparisons, as well as in diff hunk headers.

### Improved

- **Branch comparison window** — Compare branches in a separate resizable window with searchable branch selectors, a filterable folder tree, and side-by-side image previews.
- **Searchable revision selection** — Find branches more easily across Git dialogs and History filters, and select or enter a commit, branch, tag, or revision expression when comparing a file or folder.
- **Smoother History browsing** — Earlier preloading, retained loaded commits, and more efficient graph drawing improve scrolling through long histories.
- **Persistent AI usage display** — Recent Commit+ AI allowance information is cached locally per account and restored between launches.

### Fixed

- Sidebar rows no longer shift width when selection or refresh changes the scrollbar state.
- Account connection, sign-in, and upgrade sheets now keep long content scrollable within bounded heights.
- Branch comparisons automatically switch to comparing branch tips when the merge-base comparison has no changed files.
